พอร์ทัลแบบฟอร์มออนไลน์ (กรอกบนหน้าจอ แล้วพิมพ์ตามแบบกระดาษจริง)
==========================================================

โครงสร้างโฟลเดอร์
  index.html        หน้ารายการแบบฟอร์ม (ลิงก์หลักที่นำไปแปะบนเว็บหน่วยงาน)
  form.html         หน้ากรอกข้อมูลและพิมพ์ (เปิดได้ด้วย form.html?f=ชื่อสั้น เช่น form.html?f=sick)
  config.js         ตั้งค่าชื่อหน่วย ค่าเริ่มต้น และวันหยุดราชการ
  data/forms.js     ข้อมูลแบบฟอร์มทั้งหมด (สร้างด้วยเครื่องมือใน tools/ ไม่ต้องแก้ด้วยมือ)
  fonts/            ใส่ไฟล์ THSarabunPSK.ttf ที่นี่ (ดู fonts/README.txt)
  assets/           รูปที่ใช้ในแบบฟอร์ม (เช่น ตราครุฑ) สร้างโดยเครื่องมือด้านล่าง
  tools/pdf2form.py เครื่องมือเพิ่ม/ลบ/ดูรายการแบบฟอร์มจากไฟล์ PDF

1) ติดตั้งบนเซิร์ฟเวอร์ (XAMPP / Laragon)
  - คัดลอกโฟลเดอร์ forms-portal ไปไว้ที่
      XAMPP   : C:\xampp\htdocs\forms-portal
      Laragon : C:\laragon\www\forms-portal
  - เปิดทดสอบที่  http://IP-ของเซิร์ฟเวอร์/forms-portal/
  - ถ้าเครื่องอื่นเปิดไม่ได้ ให้ตรวจ Windows Firewall ว่าเปิดพอร์ต 80 ให้เครือข่ายภายใน
  - เป็นไฟล์เว็บล้วน ไม่ใช้ PHP และไม่ใช้ฐานข้อมูล จึงวางบนเว็บเซิร์ฟเวอร์ใดก็ได้
    (Apache, Nginx, IIS หรือโฮสต์เว็บของหน่วยงาน) โดยคัดลอกไฟล์ทั้งโฟลเดอร์ขึ้นไป

2) นำลิงก์ไปแปะบนเว็บหน่วยงาน
  - ลิงก์หน้ารายการ :  <a href="http://IP-หรือชื่อเว็บ/forms-portal/" target="_blank">แบบฟอร์มออนไลน์</a>
  - ลิงก์ตรงแต่ละฟอร์ม : กดปุ่ม "คัดลอกลิงก์" ที่การ์ดแต่ละใบในหน้ารายการ
      เช่น  http://IP-หรือชื่อเว็บ/forms-portal/form.html?f=personal-chief
  - แนะนำให้เปิดในแท็บใหม่ (target="_blank") เพราะการพิมพ์ในกรอบ iframe อาจเพี้ยนขนาด

3) ฟอนต์ (สำคัญ เพื่อให้ได้ขนาด 16 พอยต์ตรงตามต้นฉบับ)
  - วางไฟล์ THSarabunPSK.ttf ใน fonts/  หรือติดตั้งฟอนต์ TH Sarabun PSK บนเครื่องผู้ใช้
  - ถ้าไม่มีฟอนต์ หน้าเว็บจะย่อตัวอักษรให้พอดีและแจ้งเตือนสีแดงที่แผงด้านซ้าย

4) ตั้งค่าที่ config.js (แก้ด้วย Notepad บันทึกเป็น UTF-8)
  - title / unit  : หัวเรื่องและชื่อหน่วยที่แสดงบนหน้าเว็บ
  - defaults      : ค่าเริ่มต้น เช่น "เขียนที่" และสรรพนาม
  - holidays      : วันหยุดราชการ (ปี ค.ศ.-เดือน-วัน) เพื่อให้ระบบไม่นับเป็นวันลา
                    ระบบตัดเสาร์-อาทิตย์ให้เอง ให้ฝ่ายกำลังพลตรวจรายการวันหยุดทุกปี
                    ผู้ใช้ควรตรวจจำนวนวันลาก่อนพิมพ์ทุกครั้ง

5) เพิ่มแบบฟอร์มใหม่ในอนาคต
  ข้อกำหนดของไฟล์ต้นแบบ: PDF ขนาด A4 ที่ส่งออกจาก Word/โปรแกรมเอกสาร (มีตัวอักษรจริง
  ไม่ใช่รูปสแกน) ช่องกรอกเป็นเส้นประ "......" หรือเส้นประที่ขีดใต้ข้อความ ส่วนกรอบตาราง
  ช่องติ๊ก และรูปตราครุฑ ระบบอ่านจากไฟล์ให้เอง
  ต้องติดตั้ง Python 3 และรัน  pip install pdfplumber  ครั้งเดียว

  เปิด Command Prompt ในโฟลเดอร์ tools แล้วรัน:
    python pdf2form.py add "C:\ไฟล์\แบบฟอร์มใหม่.pdf" --pages 1 --slug leave-ordain ^
        --title "ใบลาอุปสมบท" --group "การลา" --desc "ขอลาอุปสมบท"
  - --pages  = เลขหน้าใน PDF ที่เป็นแบบฟอร์มนี้ ถ้าฟอร์มยาวหลายหน้าให้ใส่คั่นด้วยจุลภาค เช่น --pages 3,4
  - --slug   = ชื่อสั้นภาษาอังกฤษ ไม่ซ้ำกัน (ใช้ในลิงก์ form.html?f=ชื่อนี้)
  - --group  = หมวดที่แสดงในหน้ารายการ จะสร้างหมวดใหม่ให้เองถ้ายังไม่มี
  - --all-days = ให้นับเสาร์-อาทิตย์/วันหยุดเป็นวันลา (เช่น ลาคลอด)
  - รันซ้ำด้วย slug เดิมจะเป็นการแทนที่แบบฟอร์มนั้น (ใช้ตอนไฟล์ต้นฉบับเปลี่ยน)
  - ดูรายการ:  python pdf2form.py list      ลบ:  python pdf2form.py remove leave-ordain
  เสร็จแล้วรีเฟรชหน้าเว็บ แบบฟอร์มใหม่จะขึ้นในหน้ารายการทันที ไม่ต้องแก้โค้ด
  (รูปตราครุฑที่ตัดจากไฟล์จะถูกเก็บในโฟลเดอร์ assets/ ต้องอัปโหลดขึ้นเซิร์ฟเวอร์ไปด้วย)
  - ถ้าต้นฉบับใช้เลขอารบิก (เช่น แบบ 7131) ระบบจะคงเลขอารบิกไว้ ถ้าใช้เลขไทยจะแสดงเป็นเลขไทย
  ควรเปิดดูและพิมพ์ทดสอบแบบฟอร์มใหม่ทุกครั้ง ช่องที่ระบบไม่รู้จักจะแสดงเป็นช่องกรอกทั่วไป
  ตามข้อความหน้าช่อง และช่องที่รู้จัก (ชื่อ ตำแหน่ง สังกัด วันที่ จำนวนวัน จังหวัด ฯลฯ)
  จะใช้ข้อมูลร่วมกันทุกแบบฟอร์ม

  แบบฟอร์มที่มีให้ในชุดนี้ (17 รายการ)
    หมวดการลา         : ลาคลอดบุตร, ลาไปช่วยภริยาคลอดบุตร, ลาป่วย, ลาพักผ่อน, ลากิจ 3 แบบ, ขอยกเลิกวันลา
    หมวดสวัสดิการ     : บันทึกข้อความขอเบิกค่ารักษาพยาบาล, ใบเบิกเงินสวัสดิการรักษาพยาบาล (แบบ 7131),
                        บันทึกข้อความ+บันทึกคำรับรองการศึกษาบุตร, ใบเบิกเงินสวัสดิการการศึกษาของบุตร
    หมวดบ้านพักอาศัย  : ขอเข้าพักอาศัยในบ้านพักอาศัย บน.๕ (5 หน้า), แบบรายงานส่งคืนบ้านพักอาศัย,
                        แบบรายงานการตรวจสอบสภาพบ้านพักอาศัย บน.๕
    หมวดบัตรยานพาหนะ  : แบบขอบัตรยานพาหนะ หมายเลข ๒ (ข้าราชการ ทอ.), หมายเลข ๓ (บุคคลภายนอก)

  ช่องเลขประจำตัวประชาชน 13 ช่อง: พิมพ์ตัวเลขช่องเดียวในแผงซ้าย ระบบกระจายใส่ทีละช่องให้
  ตารางรถยนต์/รถจักรยานยนต์: ทุกช่องในแถวที่มีเลขลำดับเป็นช่องกรอก ตั้งชื่อตามหัวตาราง เช่น "รถยนต์ ๑ ยี่ห้อ"

  หมายเหตุเรื่องเครื่องหมาย "( )" ในแบบฟอร์ม: ระบบเปลี่ยนเป็นช่องที่กดติ๊กได้ (แสดงเป็น (✓) เมื่อเลือก)
  แบบฟอร์มที่ต้นฉบับเป็นไฟล์สแกน (เช่น แบบรายงานการตรวจสอบสภาพบ้านพักอาศัย) เครื่องมือ pdf2form
  อ่านตัวอักษรจากไฟล์ไม่ได้ ผมจัดหน้าใหม่จากพิกัดที่วัดจากภาพสแกน ถ้าจะเพิ่มแบบฟอร์มที่เป็นสแกนอีก
  ให้ส่งไฟล์มาให้จัดทำ หรือแปลงเป็นไฟล์ PDF ที่มีตัวอักษรจริงจากโปรแกรมเอกสารก่อน

6) ความปลอดภัยและข้อจำกัด
  - ข้อมูลที่ผู้ใช้กรอกอยู่ในเบราว์เซอร์ของผู้ใช้เท่านั้น ไม่ถูกส่งหรือเก็บที่เซิร์ฟเวอร์
    (ตัวเลือก "จำชื่อ-ตำแหน่ง" เก็บในเบราว์เซอร์เครื่องนั้น ปิดไว้เป็นค่าเริ่มต้น
     ไม่ควรเปิดบนเครื่องสาธารณะ)
  - ไม่มีระบบล็อกอิน ไม่มีประวัติการลา และไม่มีสายอนุมัติออนไลน์ ใช้พิมพ์เพื่อลงนามด้วยมือ
  - ถ้าไม่ต้องการให้บุคคลภายนอกเปิดได้ ให้จำกัดการเข้าถึงเฉพาะเครือข่ายภายใน หรือตั้งรหัสผ่าน
    ที่เว็บเซิร์ฟเวอร์ (เช่น .htaccess บน Apache)
  - รองรับ Chrome / Edge รุ่นปัจจุบัน
  - การพิมพ์: กระดาษ A4, ขนาด 100% (ไม่ใช่พอดีหน้า), ขอบ "ไม่มี", ปิดหัว/ท้ายกระดาษ

7) การอัปเดต
  - แก้ไฟล์ใด ให้แทนที่ไฟล์นั้นบนเซิร์ฟเวอร์ แล้วกด Ctrl+F5 ที่เบราว์เซอร์เพื่อล้างแคช
