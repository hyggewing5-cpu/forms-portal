# ระบบแบบฟอร์มออนไลน์ (Forms Portal)

กรอกแบบฟอร์มบนหน้าจอ แล้วพิมพ์ตามแบบกระดาษจริง เป็นไฟล์เว็บล้วน (HTML/JavaScript)
ข้อมูลที่ผู้ใช้กรอกอยู่ในเบราว์เซอร์ของผู้ใช้เท่านั้น ไม่ถูกส่งหรือเก็บที่เซิร์ฟเวอร์

- หน้าหลัก: `index.html`
- ตั้งค่า: `config.js`
- ข้อมูลแบบฟอร์ม: `data/forms.js` (สร้างด้วย `tools/pdf2form.py`)
- วิธีเพิ่มแบบฟอร์มใหม่และรายละเอียดอื่น: ดู `README_TH.txt`

> ห้ามอัปโหลดข้อมูลส่วนบุคคลหรือเอกสารที่กรอกแล้วขึ้น repository นี้ เพราะเป็นแบบสาธารณะ
